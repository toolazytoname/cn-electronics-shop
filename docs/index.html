本地大模型、出图出片、再打 4K，一台机器怎么拆。

从微信公众号里的 Qwen3.8-27B，聊到无头 Mac、Strix Halo、3090 / 4090 整机，最后停在闲鱼一台 12999 的光魔 G35。下面按分支收束，方便对照，不是下单按钮。

截至 2026-08-28 价格会变，以页面为准 24G 显存是门槛
当前倾向：闲鱼 ROG 光魔 G35，12999。R9 5950X + 64G DDR4 + 华硕 3090 24G 猛禽。能覆盖 27B、ComfyUI、H3 草稿和 4K 降特效游戏。不是 GLM 5.2 平替，也不是可升级平台。过保不退，先问清硬盘是不是真的 2T。

先把话说清楚

两条营销截图把期待拉歪了。分数有真的，话术过了。

Qwen3.8-27B 在 Artificial Analysis 上，xhigh 思考能打到大约 52 分，和 GLM-5.2 max 的 51–53 坐同一档。这是第三方榜，不是纯吹。但「大 28 倍还差不多」比的是 GLM 总参数 744B，干活时只激活约 40B，和 27B 稠密只差大约 1.5 倍。

日常你不会一直开最高思考。medium 掉到 44。本地跑的是 Q4，再掉一截。AA 是合成榜，啰嗦、长思考、长仓库、多工具循环，都会把体感拉开。公众号作者给 dsh 写能装的 TUI 插件，更接近真实水平：小功能可以，当主力会慢。

64G 开源模型能干嘛

买到的不是开源天花板，是 27B 这一档。

开源一线（Kimi K3、GLM-5.3、Qwen 2.4T）综合分大约 57–60，已经贴近闭源。那些是 750B–2.8T 的 MoE。64G 只能舒服跑 27B 稠密 / 30B 级小 MoE。你已经有 32G 本，27B Q4 现在就能试；64G 买的是 Q5/Q8、更长会话、少换页。

Windows 没有「8400、64G 统一内存」这个竞品。Strix Halo 64G 比那台无头 Mac 贵，带宽还更低。普通台式 64G DDR5 不是统一内存，模型只能吃显存。

为什么 Windows 更可玩

ComfyUI、H3、3A 几乎全绑 NVIDIA + CUDA。

MiniMax H3 是海螺 3.0 那种文生视频+音频，不是聊天模型。开源 H3-Base 大约 4–15 秒、768p、带立体声。ComfyUI 推荐 pruned INT8 全家桶大约 42GB 磁盘。12–16G 卡「能出片」，24G 才像草稿机。2K 成片仍走官方 API。

同一张卡不能同时占满 27B、H3 和游戏。切着用。

中国特供 D

D 不是「豪华版」。是出口管制砍过的大陆卡。显存常常一样，算力少一截。

4090D

CUDA 14592，比 4090 少约 11%

游戏大约慢 6%，AI 大约慢 6–10%。同样 24G、384-bit。云上更常见，因为国内货就是这个。买整机时别被少一个字母吓到，也别当它比 4090 强。

5090D / D V2

D 砍张量；V2 再砍显存

5090D 游戏接近满血 5090，AI 张量大约少 30%。5090D V2 把 32G / 512-bit 收到 24G / 384-bit，四个显存位空焊。游戏掉 1–2%，AI 掉 10–25%。云上标「新品」，对你是同档 24G 里更贵的 50 系。

对照那张表：4090D 24G 和 4090 24G 几乎干同一件事，D 略慢、更好租。5090D V2 24G 不要看成「新一代 24G 就该换」——显存没变，贵的是架构和溢价。

魔改 48G

英伟达没卖过 4090 48G。焊上去的容量，不是新品规格。

云上的「4090D 48G / 4090 48G」和闲鱼同款：用 3090 那种双面显存 PCB 思路，多焊颗粒，再刷 48G 的 VBIOS。核心还是 4090 / 4090D，算力不变，只是显存翻倍。2026 年夏天有人当理财炒到 2 万出头。

它唯一的好处

一张卡装下 70B Q4

不用学双卡切分，也不用 NVLink。ComfyUI 大分辨率、长上下文更不容易爆。

不要当第一台

没有官方质保，店保而已

颗粒、供电、散热都是改出来的。H3 本地本来就是 768p 草稿，为它多花一万不值。已经写在投入分档里。

NVLink 不是必须，但 3090 是消费卡里最后能插的

3090（不是 3090 Ti）卡身上有 NVLink 齿。桥大约几十到一百块。带宽远高于 PCIe，对训练和长上下文 prefills 有用；日常 llama.cpp 按层切分，PCIe 也够。4090、5090 消费卡都砍掉了 NVLink，双卡只能走主板。

光魔 G35 叠不了第二张。异形 45L、850W、横插一张猛禽三风扇。物理空间、电源、风道三条都不够。双卡是另组一台的事，不是给这台加购。

云上的「实惠双卡 3090 *2」是已经接好的机器，按小时付钱。想试 70B，先租几个小时，再决定要不要买第二张实体卡。

老平台扩不了什么

差在换代，不差在加硬盘。买来是用 3–5 年再整台换。

基本封死

CPU / 内存代际 / 旗舰卡

5950X 已是 AM4 顶。再强要换板、换 DDR5、换壳。850W 带 4090 很紧，5090 别想。3090 24G 对本地模型和 ComfyUI 已经对口，升级 4090 还是 24G，主要买速度。

还能做

加盘、换硅脂、换水冷

前面有热插拔 M.2 仓。模型 + LoRA + 游戏建议加到 4T 级。240 水冷用了四五年，泵是耗材。在这壳子里换比标准机箱麻烦。

没有 PCIe 5.0、DDR5、USB4。Wi-Fi 6。主板是整机专用 GA35DX。Win11 家庭版没有专业版那些企业功能，个人用无所谓。

验机与提问

售出不退不换，发货前问死，到货先测再确认。

  1. 固态到底几块、各多少。鲁大师里 1T 之外还有没有。
  2. GPU-Z：3090、24G、华硕猛禽，不是涡轮矿卡。
  3. 电源铭牌是不是 850W。
  4. 水冷有没有漏、泵转不转，开机听一分钟。
  5. FurMark 5–10 分钟：核心温度、显存温度。3090 显存容易过 90°C。
  6. 走闲鱼担保。外接你的 4K 屏能出 60Hz。
